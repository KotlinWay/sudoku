## Signing decision gate

The repository contains a tracked PKCS#12 file named `keystore`, added in commit
`857ec3571abb0c66a87bf64e133443a5648c9f34`. It contains the private-key alias
`sudoku`, but its public certificate cannot be read without the store password.
No local `keystore.properties`, Gradle signing properties, or relevant
environment variables are currently available.

Before removing the tracked copy or configuring Play App Signing:

1. provide the existing keystore password through ignored local configuration;
2. extract its public SHA-256 fingerprint;
3. compare it character-for-character with the RuStore fingerprint above;
4. confirm the Play Console package-name ownership prompt, if shown;
5. use the existing app signing key in Play when the fingerprints match, while
   using a separate upload key for routine uploads.

Do not generate or accept a different Play app signing key without explicit
owner approval: Android would treat builds from the two stores as different
signers and would not install one as an update over the other.
